# ClearPath

ClearPath is a student application-preparation workspace for scholarship and internship opportunities. It organizes opportunity details, requirement notes, follow-up tasks, and a final readiness checklist in one place.

## What is implemented

- Responsive public landing page and guided demo.
- Workspace creation for a scholarship or internship, with opportunity name, organization, deadline, requirement text, and optional supporting-document names.
- Requirement assessment with source excerpts, cautious statuses, filters, and user-editable status.
- Persistent checklist with task states and progress derived from saved tasks.
- Deterministic readiness audit, stored in the browser and marked out of date when underlying information changes.
- Fictional Northstar Foundation scholarship demo with known missing and uncertain evidence.
- Unit tests for eligibility derivation, source excerpts, audit findings, and task progress.

## Important current limitations

This repository started without an application, backend, database, authentication, private file storage, or AI provider. This first implementation is a local browser demo, not a production document-processing service:

- Application data is stored in `localStorage` on the current browser/device. There are no accounts, cross-device sync, server-side ownership checks, or automatic retention/deletion controls.
- Selected PDF, DOCX, and TXT files are checked for extension and size (10 MB), but their bytes are **not uploaded, parsed, or stored**. Only file names are saved. This is stated in the UI.
- For a real workspace, paste the relevant opportunity text. Requirements are split from the exact lines supplied by the user, not generated by AI. Each line is marked as needing verification; a simple keyword check labels likely mandatory items for checklist organization. This is not an eligibility determination or citation validation.
- The demo's sample statuses and audit are fictional, fixed demonstration data. Starting the demo does not analyze a real application.
- There is no configured AI provider, OCR, database, authentication, rate limiting, or production-grade authorization. Do not use this demo to store sensitive documents or deploy it as a private multi-user service.

These limitations are intentional and visible. They must be addressed before production use.

## Requirements

- **Framework:** Next.js 14 App Router
- **Language/UI:** TypeScript, React 18, plain CSS with centralized CSS variables, Lucide icons
- Node.js 18.18 or newer (Node 20 LTS recommended)
- npm

## Setup and run

```bash
npm install
npm run dev
```

Open <http://localhost:3000>. Choose **Try the guided demo** for the complete fictional assessment → tasks → audit journey, or choose **Check my application** to create a local workspace from text you provide.

The `.env.example` file documents that no environment variables are needed for the demo. The demo record is seeded locally when its CTA is opened; there are no database migrations or server seed commands. No API key should be added to client-side code.

## Checks


## Production work still required

Before production or handling real student data, add server-side authentication and authorization, a persistent database, private file storage, actual content-based file validation, safe PDF/DOCX extraction, deletion/retention controls, and a server-side AI provider adapter with strict output and source-citation validation. Implement integration and end-to-end tests for those server paths before representing them as available.

ClearPath is a preparation aid. It cannot guarantee eligibility, a scholarship award, an internship offer, or acceptance.
